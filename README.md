# 长庚明希腊占星工作台

**把讨论过的星盘、不同技法的观察和后续反馈，积累成自己的研究资料。**

做过一次咨询，听过一节案例课，或与朋友讨论过一个星盘，资料很容易散落在聊天、截图和文档中。再遇到相似问题时，往往又要从头整理。

这套工作台让 AI 接上这些工作：提取出生资料、排盘，把讨论整理成笔记，把回访存进反馈。你也可以在星盘上直接标记，再让 AI 读取已有记录，协助准备咨询、复盘或讲课。

**工具免费，代码开源。案例默认保存在自己的电脑上。**

[下载工作台](https://github.com/CGM2026/cgm-hellenistic-astrology-workbench/releases/latest) · [一句话安装](#安装与第一次使用) · [查看源码](skills/)

## 可以怎样用

### 把一份资料，变成可以继续研究的星盘

将出生文字或截图交给 AI，让它提取、核对并排盘。从本命盘出发，继续查看行运、返照、十年九月运、法达星限与黄道释放，各盘式保留自己的笔记。

> 「用这份出生资料建立案例，打开本命盘和今年的返照盘。」

### 把课堂、文章和讨论中的观察留下来

将案例文章、课堂文字或聊天资料交给能读取这些内容的 AI，让它整理出对应笔记与档案。来源和背景放在案例备注中，技法分析与实际反馈分别保存。

> 「把这段讨论整理进案例，保留不同技法各自的判断，并记录资料来源。」

记录可以持续补充。以后再看这个人或相似问题，能先读已有资料，再继续研究。

### 在星盘上记，也把研究过程分享出去

把笔记关联到具体盘面对象，用不同图层保存不同问题，以圆圈和箭头标记重点。你可以自己写，也可以让 AI 按讨论结果整理后写入。

选择星盘、笔记与档案导出图片，用于讲课、咨询资料或内容分享；姓名、地点和个人标识可在导出时调整。

### 让一次咨询有后续，让积累用于下一次

将回访补进反馈，请 AI 对照之前的判断，整理变化和需要继续追问的问题。备课时，也可以让它读取不同盘式的笔记，形成一份案例讲解提纲。

> 「读取这个案例的本命、返照笔记和回访反馈，整理下一次咨询需要询问的问题。」

## 安装与第一次使用

将下面这段话发给 WorkBuddy、Codex 或其他能操作本机文件的 AI：

```text
请从 https://github.com/CGM2026/cgm-hellenistic-astrology-workbench 的 main 分支安装「长庚明希腊占星工作台」。阅读 INSTALL.md 和 skills/cgm-astrology-workbench/SKILL.md，安装全部三个成员及必要依赖，确认默认排盘方法，再用包内虚构示例打开工作页，验证笔记能保存和重新读取。已有案例、笔记和个人设置沿用原位置。
```

装好后，先试一次：**给一份出生资料 → 排本命盘 → 请 AI 写入一条观察 → 导出分享。**
